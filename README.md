# あじさい食堂 公式ホームページ

地域の展示や案内をする「あじさい食堂」の公式ウェブサイトのリポジトリです。

## どんなプロジェクト？
地域の子どもたちや保護者の方が、安心して食事や交流を楽しめる場所「あじさい食堂」の情報を発信するために作成されたWebサイトです。

- **開催日・アクセスの案内**
- **活動内容の報告**

## このリポジトリについて
このサイトは HTML/CSS を使用し、GitHub Pages で公開されています。

- **本番サイト:** https://（あなたのユーザー名）.github.io/
- **更新方法:** `index.html` を直接編集することでサイトの内容を更新できます。
